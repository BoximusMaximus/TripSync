## Dom — Back End · PM (`trips` `activities`)

☐ **Issue: Django models from ERD.sql** · branch `trips/models-from-erd`

**Start here:** co-run the hour-0 standup with Cody, then open `resources/ERD.sql` side-by-side with `api/models.py` (branch off Cody's plumbing branch — don't wait for its merge).

**Then:** translate all six tables: `Group`, `Membership`, `Trip`, `Activity`, `TripVote`, `ActivityVote`.
- FKs: `on_delete=models.CASCADE`, explicit `related_name` (e.g. `group.trips`, `trip.activities`)

- `makemigrations` → `migrate`

**Done when:** in `manage.py shell`, you can create a Group → Trip → Activity → ActivityVote chain, and a second identical vote raises `IntegrityError`. That IntegrityError is the DB doing the double-vote blocking — say so in the PR description.
