Tech Stack Requirements

* Front-End: 
    * Vite + React.js/ts
    * React Router DOM
    * Axios
    * E2E Tests with Cypress
* Back-End:
    * Django
    * Django Rest Framework
    * PostgreSQL
    * Psycopg3
    * Token/JWT Authentication
    * Tests with Django Test Case
* Containerization
    * Docker-Compose
* Network
    * Gunicorn
    * Nginx
* CI/CD:
    * Github Actions
* Deployed on AWS EC2 t3.micro

Feature Requirements

1. Token/JWT Authentication
    1. Register
    2. Login 
    3. Logout
    4. Confirmation
2. 2 CRUD Resource (not a user profile)
3. Minimum of two third party API's:
    1. 1 client side
    2. 1 server side (requires authentication)
4. Dynamic User Interface
5. Application must be able to handle user errors with appropriate http responses and or UI interfaces
